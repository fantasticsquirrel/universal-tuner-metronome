# Tunera 0.2.6 test preview

Version 0.2.6 / Android versionCode 9; package `app.tunera.mobile`; Android 10+
(API 29); target API 36. Intended as a universal, four-ABI test APK.

## Changes

- Remove READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE, INTERNET,
  ACCESS_NETWORK_STATE, and SYSTEM_ALERT_WINDOW from release builds.
- Retain RECORD_AUDIO, MODIFY_AUDIO_SETTINGS, VIBRATE, WAKE_LOCK, and the
  signature-protected `app.tunera.mobile.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`.
- Keep the existing keep-screen-awake setting and playback wake-lock behavior;
  neither setting is forced on. The visible-screen flag and WAKE_LOCK are separate.
- Recheck microphone permission before Android native foreground resume, with
  cancellation/stale-result guards. Fresh installs still prompt only after an
  explicit listening action. Existing grants can auto-start the tuner.
- Add a strict merged-manifest/APK permission checker and regression tests.
- Keep debug Metro networking available. Explicitly disable OTA in configuration.
- Preserve Concert A input/default behavior, stored preferences, DSP, native audio
  capture, dependency versions, and simultaneous tuner/metronome operation.

## Verification required before distributing

Run TypeScript, ESLint, the full JavaScript tests, permission-policy tests, native
host and Android native unit tests, all-ABI release assembly and fatal lint. Check
actual APK permissions, identity, signature, checksum, ZIP integrity and alignment,
embedded JavaScript/native bridge, and native ELF layout. Record measured results
and source provenance in the release assets; a planned check is not a passed check.

## Compatibility and honest limits

Retain the previous preview's shared Android Debug signer to preserve update
compatibility. Certificate SHA-256:
`fac61745dc0903786fb9ede62a962b399f7348f0bb6f899b8332667591033b9c`.
This is a test-preview signing identity, not production-strength app-store signing.
Do not uninstall or clear app data to hide update failures.

Physical-device microphone, permission revocation, offline playback, screen-lock,
lifecycle, keyboard/IME, responsiveness, power and thermals remain unverified unless
explicitly recorded with the build. Static 16 KB checks are not a runtime smoke
test. The previous preview has two known full Android lint errors (API 33 splash
attribute and dependency notification code) and 40 warnings; rerun and report the
new result without suppressing checks or adding unrelated permissions.

Microphone audio stays in memory and is not saved/uploaded. App-private settings
can participate in OS-managed backup. Media3 platform diagnostics remain subject
to Android's diagnostics settings. See [the audit](../android-permissions.md).
No paid build service or GitHub Actions is authorized for this release.
