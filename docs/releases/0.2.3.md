# Tunera 0.2.3 — Android tuner performance

Android package `app.tunera.mobile`, versionCode **6** (previous GitHub 0.2.2 stable and Tab M9 test.3 APKs both use versionCode 5). Provider history was also checked before selecting this code; its two historical Android builds use code 1. No permission change is intended in this release.

## Changes

- Native Android avoids constructing unused JavaScript audio buffers on each pitch update.
- Smaller capture reads allow more regular analysis without shrinking the recorder safety buffer or bass-analysis windows.
- Early-exit pitch detection avoids unused lag calculations while preserving baseline result bits in the regression corpus.
- Live pitch rendering is isolated from screen controls/metronome pulses; the gauge uses native-driven movement and honors reduced motion.
- Release preflight aligns Expo/Constants/Linking/Router patch versions and Jest/Jest types with the installed SDK's compatibility requirements. No tuning algorithm or sample-window changes are made by that alignment; all regression suites are re-run.

## Distribution and compatibility

Publish the canonical merged source as a GitHub APK release, retaining the prior universal APK architectures (`armeabi-v7a`, `arm64-v8a`, `x86`, `x86_64`). This is not a Google Play submission.

The existing GitHub stable and Tab M9 test APKs are signed with the **Android Debug certificate**, SHA-256:

```text
fac61745dc0903786fb9ede62a962b399f7348f0bb6f899b8332667591033b9c
```

Continue that exact existing signing identity for in-place update compatibility; do not replace it with a new unrelated key or ask users to uninstall/delete data. This shared debug signing identity is not a production-strength app-store signing setup. A future signing migration requires a separate compatibility plan. The release APK must be verified against this independently downloaded prior-release certificate before publication.

## Verification and limits

The underlying optimization was independently reviewed, passed 88 JavaScript tests and 14 native tests, and built successfully for ARM in local/remote release mode. Re-run final-revision PR/main CI and verify the canonical versioned APK before publishing. Bind the release tag and attached artifact provenance to the exact merged source; preserve APK hash, signer and architecture readbacks with the artifact.

Host benchmarks and simulated capture timing are not measurements on the user's lower-end device. No connected physical device was available. Device microphone latency, UI frame rate, battery/thermals and lifecycle remain unverified and must be stated in the published release notes. Existing boundary/harmonic accuracy limitations are unchanged; this release is performance work, not a detector-accuracy rewrite.
